# 四象限对话法（Four-Quadrant Method）

[English](./README.md)

> 一套与 AI 协作的实用思考框架：让未知显形，尽早暴露盲点，让任务的每一步都走在正确的轨道上。

本仓库收录**四象限对话法**（Four-Quadrant Method），一套最初以 AI 助手 skill 形式编写的方法论（见 [`SKILL.md`](./SKILL.md)）。它帮助你与 AI 一起管理"已经知道什么、还不知道什么"，以及最重要的——**不知道自己不知道什么**。

## 这是什么？

处理任何任务时，你的知识状态可以分成四类：

| | 未掌握 | 已掌握 |
|---|---|---|
| **已意识到** | **Q2 已知的未知**（求知区） | **Q1 已知的已知**（目标区） |
| **未意识到** | **Q3 未知的未知**（盲点区） | **Q4 未知的已知**（隐性能力区） |

- **Q1（目标区）**：清楚知道自己会什么、手里有什么。
- **Q2（求知区）**：知道自己不会什么，需要学习或获取。
- **Q3（盲点区）**：不知道自己不知道什么——任务中最大的风险来源。
- **Q4（隐性区）**：会但没意识到——沉默的资产。

两条核心原则：

1. **让问题向 Q1 迁移**——把每个问题在四象限之间转化，直到它成为"已意识到、已掌握"。
2. **小成本暴露未知**——执行前尽量用最小的代价、最早的时间暴露 Q3 盲点。

## 怎么用？

方法分三个级别，默认适用于任何规模的任务：

- **T0 轻量扫描**（默认，一切任务）：开工前各用一句话列出 Q1（已知）、Q2（待补）、Q3（可能遗漏）。这不是可选项——任务越简单清单越短，但对"意识"本身从不跳过。
- **T1 完整流程**（复杂 / 模糊 / 高风险 / 陌生领域任务）：采访五问 → 制作最小原型暴露未知 → 制定标注了 Q1 已确认、Q2 待决策、Q3 待验证假设的计划。
- **T2 强制检查**（执行中与结束后）：每个步骤实时记录偏离（新情况 / 变更原因 / 关键决定）；任务结束强制复盘：原计划 vs 实际 → 偏离点 → 新暴露的未知 → 后续动作。

## 如何使用

- **作为 AI skill**：把 [`SKILL.md`](./SKILL.md) 加载给你的 AI 助手。它包含完整的操作手册——四象限、分级使用表、采访五问、计划标注模板、步骤偏离记录模板、复盘报告模板。
- **作为通用方法论**：你也可以在任何协作中自行套用 T0 / T1 / T2，有没有 AI 都适用。模板自包含，核心思想与语言无关。
